# Restaurant POS Application

## Project Overview
A Restaurant Point of Sale (POS) frontend developed using React and TypeScript. The application helps display restaurant categories and menu items.

## Technologies Used
- React.js
- TypeScript
- Tailwind CSS
- Axios
- HTML5 and CSS3

## Features
- Display restaurant categories
- Display menu items
- Filter items by category
- Fetch data using REST API integration
- Responsive user interface

## Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the application:

   ```bash
   npm run dev
   ```
